# Code of Conduct

This project aims to support respectful technical collaboration.

Contributors and maintainers should:

- Discuss code and technical ideas constructively, using evidence where possible.
- Respect different experience levels, backgrounds, and viewpoints.
- Avoid harassment, threats, discriminatory comments, or sharing private information.
- Focus reviews on behavior and changes rather than personal criticism.

Maintainers may edit or remove inappropriate content and restrict participation when necessary. Report a conduct concern privately to the repository maintainer through a private channel; do not expose personal information in a public issue.
